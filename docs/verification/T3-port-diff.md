## Transactions

The body of `Run` contains no call that modifies the Revit document. The only statements that touch state are
`System.IO.Directory.CreateDirectory` (file system), `ExternalEvent.Create` and `ev.Raise()`. All document changes
are in `NavHandler` inside explicit `new Transaction(...)` blocks that were not changed. No extra transaction was added.
