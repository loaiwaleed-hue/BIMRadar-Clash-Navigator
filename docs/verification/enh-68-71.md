# Verification: enhancements #68 - #71

**Kind of check: code read only. This is not a Revit test.** Nothing was compiled or run here. The owner tests it in Revit on a model copy. Writes (view display style, detail level) are proven only by that test.

Changes are marked `// #NN` in the code.

## #68 Shaded + Medium (`Navigator/NavHandler.cs`)
- New `ShadedMedium(View v)`. It sets `DisplayStyle.Shading` and `ViewDetailLevel.Medium`, each in its own try/catch. It returns early when `ViewTemplateId != ElementId.InvalidElementId`.
- Called in `Execute` (main "Viewpoint Navigator" transaction, after `SetOrientation`) and in `DuplicateOrtho` (after `SetOrientation`, once the template has been cleared).
- `View.DisplayStyle` and `View.DetailLevel` exist in Revit 2022-2027 (not checked against revitapidocs here; the sandbox has no network). Nothing is version-specific, so `Compat.cs` is untouched.

## #69 No isolate button for Revizto (`NavForm.cs`, `NavHandler.cs`)
- `NavForm` constructor: `noIso = isVp || isClash || isRevizto`. The button is hidden and the snapshot button takes the full width.
- `NavHandler.Execute`: an "Isolate" action on a Revizto source resets `Isolated = false`. Both `ApplyIsolation` calls (`Execute`, `DuplicateOrtho`) use `Isolated && !Source.StartsWith("Revizto")`, so Revizto never isolates. Clashes stay always isolated.

## #70 / #71 Why-in-list panel (`NavForm.cs`)
- New labels `lblWhy1` and `lblWhy2` (8.5 pt, 16 px each) under `lblPic`, and new method `ShowWhy(VpCam)`.
- Line 1 (#71): a Revizto issue with an empty `c.Model` shows amber "Not anchored to a model" plus " · zone Z" and/or " · room R". Otherwise a grey "Model: ..." line plus zone/room.
- Line 2 (#70): only while a search is active. It reads the existing `hitGroup` (built by `BuildSearch` from `NavHandler.SearchGroup`). The group logic is not duplicated. Texts:
  - `M:` gives "Matched: anchor model X".
  - `X` gives "Matched: zone/room (anchored to another model Y)".
  - `Z` gives "Matched: zone Z".
  - `R` gives "Matched: room R".
  - `U` gives "Not located".
- `ShowWhy` is called from `Sync` and at the end of `ApplyModelSearch`, so a search change updates it.

## Layout shifts (`NavForm` constructor)
- The panel needs 34 px more at the bottom. The base client height went from 968 to 1002 (Revizto and viewpoints) and from 1048 to 1082 (clash), still capped at the work-area height minus 50.
- The picture height now reserves `clientH - y - 74` (was `- 40`). On a tall screen the picture keeps its old size.
- `lblPic` is unchanged. `lblWhy1` is at `y + picH + 38` and `lblWhy2` at `y + picH + 54`. The grow check is now `y + picH + 74`.
- Controls above the picture did not move. Only the picture shrinks on a short screen (minimum 140 px).
